## Coin

Source: `src/components/Coin.tsx`

**Use it for:** The coin icon next to an amount of coins.

**Not for:** Decoration. If there is no coin amount beside it, leave it out.

**Rules:** Colours come from the brand's gold shades. Set only the size.

```tsx
<Coin size={24} />
```

Props:

```ts
  /** width and height in pixels, default 24 */
  size?: number;
```

## DailyStreak

Source: `src/components/DailyStreak.tsx`

**Use it for:** A row of rewards for consecutive days, with today marked and past days checked off.

**Not for:** Progress that is not day by day (use LevelBar).

**Rules:** It holds no state of its own about days: pass claimed (how many days are collected) and canClaim (is today still waiting), and update them in onClaim. The last day is shown as the bonus day. Use DAILY_REWARDS from the economy helper for the amounts.

```tsx
<DailyStreak rewards={DAILY_REWARDS} claimed={3} canClaim onClaim={(day) => {}} />
```

Props:

```ts
  rewards: readonly number[];
  /** how many days are already collected (0 to rewards.length) */
  claimed: number;
  /** is today's reward still waiting? */
  canClaim: boolean;
  onClaim: (dayIndex: number) => void;
```

## LevelBar

Source: `src/components/LevelBar.tsx`

**Use it for:** Progress toward a threshold, with the current step in a round badge. By default it shows a level and its XP. With max, unit and badgeLabel it shows any goal, for example 7 of 10 spins in a weekly challenge.

**Not for:** Time left (OfferCard has the countdown), a wallet balance, or a reward amount.

**Rules:** It never moves by itself; it draws the numbers it is given. When the badge number changes, the badge pops. Pass snap for the one render where the bar must jump to empty without animating. For level and XP, use the useLevelProgress helper, which produces level, xp and snap for you.

```tsx
<LevelBar level={4} xp={60} />
<LevelBar level={2} xp={7} max={10} unit="spins" badgeLabel="Week" />
```

Props:

```ts
  /** the number in the badge */
  level: number;
  /** progress so far */
  xp: number;
  /** the threshold; defaults to the XP the level curve asks for at this level */
  max?: number;
  /** word after the numbers, default "XP" */
  unit?: string;
  /** small word above the badge number, default "Level" */
  badgeLabel?: string;
  /** true for one render when the bar must jump without animating (new level, empty bar) */
  snap?: boolean;
```

## OfferCard

Source: `src/components/OfferCard.tsx`

**Use it for:** Something the player can buy: a coin pack or a bundle, with its price on the button.

**Not for:** Free rewards (use RewardChest) or progress (use LevelBar).

**Rules:** The anatomy is fixed: badge, name, coins, bonus, price button, timer. Empty rows keep their height, so cards in a row line up. At most one featured card per row. Take name, coins, bonus and price from PACKS in the economy helper so the numbers stay true; do not type amounts by hand. endsInSeconds adds a live countdown and disables the button at zero.

```tsx
<OfferCard name="Starter" coins={5000} price="$1.99" onBuy={() => {}} />
```

Props:

```ts
  name: string;
  coins: number;
  /** extra coins in percent, shown as "+50% bonus" */
  bonus?: number;
  price: string;
  badge?: string;
  featured?: boolean;
  /** show a live countdown that starts at this many seconds */
  endsInSeconds?: number;
  onBuy?: () => void;
```

## RewardChest

Source: `src/components/RewardChest.tsx`

**Use it for:** The payoff moment. A reward the player has earned is revealed, counted up and collected.

**Not for:** Showing a price, a balance or progress. Not for something the player still has to pay for (that is OfferCard).

**Rules:** One chest per reward. tier only sets the gem and glow colour, in rising order mini, minor, major, grand; pick it by how big this reward is next to the others in the same flow. With autoPlay it opens as soon as it appears and again when tier or amount change; without it the player taps Open. Mount it only when there is a reward to show. onStateChange reports idle, opening, open, claimed.

```tsx
<RewardChest tier="major" amount={2500} autoPlay />
```

Props:

```ts
  tier: Tier;
  amount: number;
  onStateChange?: (state: ChestState) => void;
  /** open as soon as it appears, and again whenever tier or amount change */
  autoPlay?: boolean;
```

# Helpers

Data and logic a template may import from `src/lib`.

## economy

Source: `src/lib/economy.ts`

Every reward number. Import from here instead of typing amounts: xpForLevel(level), levelReward(level), DAILY_REWARDS (seven daily amounts), WEEKLY_CHALLENGE (goal and reward), PACKS with packCoins(pack) and bestValuePack(), formatCoins(n).

**Rules:** If a mechanic needs a new reward amount, add it here as a named constant or function with a comment, never inline in a template.

## useCountdown

Source: `src/lib/useCountdown.ts`

const { label, expired } = useCountdown(seconds) gives a ticking "H:MM:SS" label. OfferCard already uses it through endsInSeconds; reach for it directly only for a deadline that is not on an offer.

## useLevelProgress

Source: `src/lib/useLevelProgress.ts`

Level and XP state for a LevelBar. const { level, xp, snap, gain } = useLevelProgress(startLevel, startXp, onLevelUp). Call gain(amount) to add XP; it plays the fill, the level change and the remainder in order, and calls onLevelUp(newLevel) for each level crossed.

**Rules:** Pass level, xp and snap straight to LevelBar. Do not write timers in a template to sequence this yourself.
